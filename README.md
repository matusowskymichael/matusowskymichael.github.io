# Michael Matusowsky

Personal homepage at https://matusowskymichael.github.io/.

A responsive, buildless static site. No JavaScript, cookies, analytics, external fonts or runtime dependencies.

## Preview

Run `python -m http.server 8000` from this directory, then open http://localhost:8000/.

## Publication

GitHub Pages serves the root of the `main` branch. Update the HTML and local assets together.
